Input Display Web Component

A simple web component that displays input text in real-time

Usage Instructions

To use this component from jsDelivr CDN, add the following to your HTML:

Option 1: From GitHub (Recommended)

<!-- Load the component -->
<script type="module" src="https://cdn.jsdelivr.net/gh/yourusername/yourrepo@main/input-display-component.js"></script>

<!-- Use the component -->
<input-display-component></input-display-component>

Option 2: From npm (if published)

<!-- Load the component -->
<script type="module" src="https://cdn.jsdelivr.net/npm/package-name@latest/input-display-component.js"></script>

<!-- Use the component -->
<input-display-component></input-display-component>

Optional Attributes

<input-display-component 
  placeholder="Custom placeholder text"
  label="Custom Label">
</input-display-component>
